Facts (Science) vs Possibility (Future)

Observe Situation #1

"If you heat ice..."

"...it melts."

Question: Is this just today? Or always?

ALWAYS TRUE (FACT)

Zero Conditional (0)

THE RULES (FACTS)

Structure

IF + Present Simple, ... Present Simple

If you mix red and blue, you get purple.

When to use it?

  • Scientific facts
  • General truths
  • Rules / Instructions
  • "When" can often replace "If"

Observe Situation #2

"If it rains tomorrow..."

"...I will stay home."

Question: Is this a scientific fact? Or a future plan?

POSSIBLE FUTURE

First Conditional (1)

REAL POSSIBILITY

Structure

IF + Present Simple, ... WILL + Verb

If I study hard, I will pass the exam.

When to use it?

  • Future plans
  • Promises
  • Predictions
  • Warnings

0 vs 1: The Difference

ZERO

If I drink coffee...

"...I can't sleep."

(This is a biological fact for me. Always.)

FIRST

If I drink coffee tonight...

"...I will finish the report."

(This is a specific plan for tonight.)
