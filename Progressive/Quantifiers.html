Quantifiers

Countable vs. Non-Countable

Apples, Friends, Cars

Water, Money, Time

The Big Difference

COUNTABLE

1, 2, 3 Things

Dogs, Books, Ideas.

Many, Few, Several

UNCOUNTABLE

Mass / Liquid / Abstract

Water, Love, Information.

Much, Little, Less

1. Almost All (~95%)

Countable

"Almost all (of the) students are here."

Uncountable

"Almost all (of the) water is gone."

Rule: "Almost All" works for BOTH types.

2. Large Quantity

SO MANY

Countable Only

"There are so many people!"

SO MUCH

Uncountable Only

"There is so much traffic!"

3. Medium Quantity

SEVERAL

Countable Only

"I read several books."

(Means: More than a few, but not "many")

4. Small Quantity (Positive Tone)

A FEW

Countable

"I have a few friends."

(I'm happy, I have some)

A LITTLE

Uncountable

"I have a little money."

(Enough to buy lunch)

5. Very Small Quantity (Negative/Emphatic)

Countable

Very / So FEW

"There are so few chairs."

(Problem: Not enough!)

Uncountable

Very / So LITTLE

"We have so little time."

(Problem: Hurry up!)

6. Almost Zero (~1%)

ALMOST NO + Noun

"There are almost no apples."

"There is almost no water."

ALMOST NONE

(No Noun)

"Do we have apples? Almost none."

Use "Almost No" with the word. Use "Almost None" alone.
